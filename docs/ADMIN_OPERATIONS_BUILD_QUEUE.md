# Udo Admin Operations Build Queue

This queue turns the Filament admin panel from basic CRUD into the control system for running Udo as a real wedding platform. Work should move in ID order unless a production blocker requires reprioritization.

## Completion Gate

An item is done only when:

- The admin user can complete the workflow from the Filament panel without touching the database directly.
- Risky actions have clear labels, confirmations, and guardrails.
- The underlying backend behavior is covered by tests or existing verified service contracts.
- Local verification has run with Herd PHP 8.3.
- Any remaining limitation is documented in this file.
