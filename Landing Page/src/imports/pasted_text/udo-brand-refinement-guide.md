Do not redesign Udo from scratch. Do not change the overall structure, brand direction, or the premium calm tone we have already established. This is a refinement and unification pass. Keep the current layout direction, but overhaul the visual system so the page feels intentional, readable, premium, modern, soft, and fully cohesive. The result should feel like a polished luxury consumer product, not a template, not a wedding blog, and not a generic pastel startup landing page.

PRIMARY GOAL

Fix the landing page so that:

every section is clearly readable at first glance
the colors feel unified across the full page
the brand feels premium and elegant, not cheap or washed out
contrast is improved everywhere text currently disappears
whitespace is reduced where it feels empty or unfinished
the logo / brand treatment in the top left feels more elevated and intentional
the page clearly communicates who Udo is for, what it does, why it matters, and how it helps
the page retains the soft pink / green / neutral direction we have been using, but with much stronger discipline and clarity
1. OVERALL VISUAL DIRECTION

The page should feel like:

calm luxury

modern premium consumer software
emotionally warm but highly structured
effortless and intentional

Avoid anything that feels:

The emotional reference is:
peaceful, polished, expensive, quiet confidence

2. COLOR SYSTEM — MUST BE FULLY UNIFIED

Create one cohesive color system across the entire page. Right now different sections feel like they belong to different websites. Fix that.

Use this color logic consistently:
A. Base / page background

Use a warm ivory / warm off-white background across the default page sections.
It should not feel grey, cold, or stark white.

B. Section background variation

Alternate sections using:

warm ivory
very soft blush-beige tint
occasional slightly richer warm nude/beige section block

The alternation should feel subtle and elegant, not striped or random.

C. Accent pink

Use a dusty rose / muted blush pink as the main brand accent.

Use this pink for:

CTA buttons
selective highlight words in headings
small icons
soft chips / tags
subtle UI emphasis

Do not use too many different pinks. One main pink accent, plus perhaps one lighter tint of that same pink.

D. Accent green

Use a deep muted sage / desaturated green as the grounding brand accent.

Use green for:

selected section headings
premium serif headlines
occasional sub-brand emphasis
trust / calm / organization cues

Do not let the green become too dark, too forest-heavy, or too masculine. Keep it refined and muted.

E. Text colors

This is where the page is currently failing.

Use:

primary heading color: deep charcoal
secondary premium heading color: muted dark green where appropriate
body text: medium-dark warm taupe-grey, clearly readable
supporting text: slightly lighter warm grey, but still readable
never use body copy that blends into the background
F. Cards

Cards should be either:

a very soft warm cream on ivory backgrounds
or a slightly deeper blush/neutral surface on tinted backgrounds

Cards must always be visibly separate from the section background.

3. CONTRAST FIXES — THIS IS THE MOST IMPORTANT TASK

A number of sections currently look elegant in theory but fail in practice because the text and surfaces are too close in value. Fix all of that.

Rules:
all headings must be immediately readable
all card titles must be readable at a glance
all body copy must be readable without straining
all icons must remain visible
no section should rely on extremely pale beige text on a pale beige background
no “pretty but invisible” design choices
Specifically fix:
“Designed for the full journey” section where the cards are too faint
the feature grid sections where card background and section background are too similar
any section where beige text sits on beige
the lighter green headings if they are not reading strongly enough
the pink text if it becomes too pale against the ivory background

Make the design feel soft, but not faded.

The final top-left corner should feel like a real premium brand, not a placeholder.

5. TYPOGRAPHY SYSTEM — MUST FEEL CLASSY AND EXPENSIVE

Use a clear two-font system or a strong hierarchy that mimics one:

Headline style

Use an elegant serif for major headings and premium moments.
This serif should feel:

refined

Supporting/body style

Use a clean sans serif for:

paragraphs
