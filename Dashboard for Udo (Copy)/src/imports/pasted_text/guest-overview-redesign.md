The biggest issue right now is not the design quality — the components themselves are actually clean and modern now. The issue is information hierarchy and repetition. Almost every section is saying the same thing in different ways:

* pending RSVP
* incomplete guests
* guests missing meals
* guests missing seating
* progress bars
* action cards
* reminders
* activity feed

All of these are conceptually overlapping.

Right now the page feels like:
“dashboard stacked on dashboard stacked on dashboard.”

Instead, the Guests Overview should feel like:
“one elegant command center.”

The bride should understand the entire state of her guest experience within 5–7 seconds.

Right now she has to mentally reconcile too many boxes.

---

# THE MAIN FIX

You need to restructure the page into 5 clear emotional zones:

1. Wedding Guest Health Snapshot
2. Immediate Actions
3. Guest Progress Journey
4. Important Guest Groups
5. Intelligent Insights (optional/minimized)

That’s it.

You do NOT need:

* Recent activity
* Multiple CTA sections
* Repeated pending response mentions
* Separate action required + take action
* Multiple progress systems

Those are causing clutter.
